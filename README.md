# PDF 比對 (pdf-diff)

在瀏覽器中比對兩份 PDF 的文字內容，並以顏色標示差異。純前端，檔案不會上傳到任何伺服器。

## 功能

- 拖曳或選擇兩份 PDF（也可一次拖入兩個檔案）
- 並排顯示，逐行對齊；修改行內以字詞/字元層級標示新增與刪除，支援中英文
- 選項：忽略大小寫、忽略空白差異、只顯示差異與前後文 / 顯示全部
- 差異導覽：「上一處 / 下一處」按鈕，或鍵盤 `p` / `n`
- **輸出兩份已劃記的 PDF**：修訂前（紅色標出被刪除／修改的內容）、修訂後（綠色標出新增／修改的內容），可直接用於送審
- 自動排除每頁重複的頁首/頁尾（例如產生日期、頁碼），避免每頁都被判成差異
- 可選擇是否在輸出時移除原檔既有的螢光標示（只影響輸出檔，不會改動原始檔案）
- 支援直式頁面加 `/Rotate` 的橫向版面
- 支援加密 PDF（會詢問密碼）
- 深色模式自動跟隨系統

## 使用

線上版：啟用 GitHub Pages 後開啟 `https://<帳號>.github.io/pdf-diff/`。

本機執行（需用 HTTP 伺服器，直接雙擊 `index.html` 時瀏覽器會擋 Web Worker）：

```sh
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 限制

- 比對的是「文字內容」，不是外觀；圖片、圖表的差異不會被偵測。
- 字詞層級的標示位置是依字寬估算，個別情況可能與實際文字略有偏移，送審前建議抽查。
- 掃描檔（沒有可選取文字的 PDF）無法比對，需要先做 OCR。
- 多欄排版或表格依 PDF 內部的文字順序逐行讀取，順序若與視覺閱讀順序不同，結果會受影響。

## 結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 介面與互動 |
| `core.js` | 文字擷取成行（含座標）、行級與字詞級 diff、標示範圍計算（瀏覽器與 Node 皆可用） |
| `marker.js` | 以 pdf-lib 將標示畫到 PDF 上（乘法混合，不遮住文字） |
| `vendor/` | pdf.js 3.11.174（Apache-2.0）、jsdiff 5.2.0（BSD-3-Clause）、pdf-lib 1.17.1（MIT）與中文 CMap |
